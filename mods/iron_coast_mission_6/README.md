# Iron Coast — Mission 6: Iron Crown

API 1 package, version 1.0.2. Enable it in Mods at the main menu and apply the selection. The normal dependency selection also enables `iron_coast_scout`, `iron_coast_turret`, `iron_coast_boss_6`, `iron_coast_music`, `pulse_cannon`, `seeker_swarm`, `ion_lance`.

Mission `iron_coast_mission_6:mission_06`: **Iron Coast 6 — Iron Crown**. Destroy all six batteries, the Fleet and Iron Crown. Required ground objectives remain reachable; escaping optional aircraft never counts as a kill. Elapsed time alone does not finish the mission.

Scheduled spawn totals for Training / Rookie / Veteran / Elite are **64 / 92 / 120 / 145**. These are enabled scheduled entries, not simultaneous live-enemy counts. Groups can overlap when earlier enemies survive.

Align the forward guns with required targets while moving around incoming shots. If carried, select Field Repair or coolant with Cycle and use Special: they restore 25 or 30 energy respectively and consume a real item. Shop purchases and refills still cost credits.

Version 1.0.2 removes ten additional Elite reinforcement entries to leave recovery space before the Fleet. Training, Rookie and Veteran schedules, all required targets, boss health and objective scripts are unchanged.

## Equipment supplied by the mission

The mission loans an Ion Lance when it is not already carried and an inventory slot is available. Use Cycle to select Ion Lance, then hold Fire (or use Special) to fire it. The loan is returned at mission end; a missing final inventory entry does not mean it was unused.
