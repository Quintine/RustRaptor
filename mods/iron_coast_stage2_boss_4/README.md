# Iron Coast II — Floodgate

Independent API1 enemy package: enable this mod alone to make `iron_coast_stage2_boss_4:unit` available to missions. It does not add a playable campaign, shop item, dependency, override or equipment grant. Mission4 uses this boss; other mod missions can reference the unit and its `:defeated` objective.

Floodgate is a104×64 ground boss with280 normal health and2800 credit reward. It enters at2pixels per tick then holds y24, patrolling x68–148 at2pixels per tick. Each salvo gives a14-tick visual/audio warning and movement pause. Two outward3-damage shells leave a central safe lane every76ticks above halfhealth; below halfhealth two extra inward-positioned outward shells join a64-tick cycle. All projectiles have finite standard collision behavior. The actual spawn-health snapshot defines the half-health transition, so easier difficulty begins in the first phase despite the engine halving starting health.

State is deterministic and per entity. Arrival and fire clocks are independent. Dead or missing snapshots cannot shoot; actual deaths increment `iron_coast_stage2_boss_4:defeated` once, while despawn/escape never count. Spawn clears reused entity-ID flags before checking the live snapshot, allowing saved-state mission replays even when the engine collects a ground projectile death on the following step. The boss never completes a mission or pays a script credit reward; the engine grants its one defined reward.

The unit and shell have genuine transparent SD/8×HD PNGs and untouched builtin masters, with tracked `prompts/`, per-art provenance, `asset-report.json`, `audio-recipe.json` and `build_assets.py`.
