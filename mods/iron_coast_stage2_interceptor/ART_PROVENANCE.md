# Needlewing artwork and audio provenance

The two `art/*-generated-v1.png` files are unchanged outputs of the built-in image generator. Their exact built-in paths, output hints, generation job/lease IDs, original bytes SHA-256 and saved prompt paths are recorded in `provenance-unit-v1.json` and `provenance-projectile-v1.json`. They were generated as transparent new enemy/artwork designs; the originals were style references, not replacement sprite authority. No decoded original reference image is distributed inside this mod.

The authentic catalog style references were viewed before generation: the enemy reference is asset `102f8`, and the projectile reference is `101d6`. Their decoded reference SHA-256 values are retained in the provenance records. Original gray metal, compact top-down silhouette, restrained highlights and readable small logical canvases informed these new designs. The exact palette used for local renderer review is recorded in the external validation handoff.

`prepare_art.rs` is the complete reproducible preparation recipe. It crops only completely transparent outer margins (every input pixel with alpha at least one remains within the recorded crop), preserves the occupied aspect ratio, fits and centers the artwork inside the declared logical canvas with padding, and creates an 8× HD canvas using premultiplied-alpha Lanczos3. SD uses the same floor-nearest sample positions as the renderer at logical size, retaining bright projectile cores and matching the SD/HD silhouette placement at 1×. The production PNG loader performs its normal alpha threshold and original-palette conversion; this package does not change that policy. Native details necessarily simplify at SD and the smallest indexed HD sizes.

`art-qa.json` records every raw/SD/HD hash, dimensions, crop, occupied fit, offsets, logical origin `[0,0]`, single-frame count and alpha-threshold bounds. No opaque edge touches the sprite canvas. HD and SD canvases have exactly the same aspect and logical placement. Generated masters remain untouched; only derived artwork is prepared.

To reproduce preparation, compile `prepare_art.rs` against the project's locked `image`, `serde_json` and `sha2` crates, then pass this mod folder to the resulting executable. The checked local compiler arguments are retained in the external development validation record. This helper writes only derived PNGs and `art-qa.json` in the supplied mod.

`generate_audio.py` creates original effects with seeded chirps and filtered noise using the Python standard library. It uses no original recordings, external audio service or nondeterministic noise source. Run `python3 generate_audio.py` from this mod folder to reproduce the three WAVs and their recipe. All are mono 22050 Hz 16-bit PCM, with short attack/release envelopes and normalized peaks below clipping. Exact seeds, lengths, peak/RMS and SHA-256 values are in `audio-recipe.json`.

Local visual review covers the unchanged raw outputs, both prepared modes and all indexed renderer outputs at scales 1–4. These diagnostic galleries do not claim live whole-mission rendering. SoundBank/Mixer tests confirm that all effects decode, queue and produce nonzero unclipped output; they do not measure a user's speakers.
