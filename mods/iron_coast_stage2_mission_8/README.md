# Iron Coast II 8: Black Tide

API 1 package, version 1.0.1. Enable it in Mods at the main menu and apply the selection. The normal dependency selection also enables `iron_coast_stage2_interceptor`, `iron_coast_stage2_siege`, `iron_coast_stage2_skimmer`, `iron_coast_stage2_boss_8`, `iron_coast_stage2_music`.

Mission `iron_coast_stage2_mission_8:mission_08`: **Iron Coast II 8 — Black Tide**. Destroy five siege units, four skimmers and the boss. Required ground objectives remain reachable; escaping optional aircraft never counts as a kill. Elapsed time alone does not finish the mission.

Scheduled spawn totals for Training / Rookie / Veteran / Elite are **61 / 69 / 81 / 97**. These are enabled scheduled entries, not simultaneous live-enemy counts. Groups can overlap when earlier enemies survive.

Align the forward guns with required targets while moving around incoming shots. If carried, select Field Repair or coolant with Cycle and use Special: they restore 25 or 30 energy respectively and consume a real item. Shop purchases and refills still cost credits.
