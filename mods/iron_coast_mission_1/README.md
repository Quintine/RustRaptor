# Iron Coast — Mission 1: Breakwater

API 1 package, version 1.0.1. Enable it in Mods at the main menu and apply the selection. The normal dependency selection also enables `iron_coast_scout`, `iron_coast_turret`, `iron_coast_boss`, `pulse_cannon`, `seeker_swarm`, `ion_lance`, `iron_coast_music`.

Mission `iron_coast_mission_1:mission_01`: **Iron Coast 1 — Breakwater**. Destroy two required turrets and the Command Cruiser. Required ground objectives remain reachable; escaping optional aircraft never counts as a kill. Elapsed time alone does not finish the mission.

Scheduled spawn totals for Training / Rookie / Veteran / Elite are **25 / 34 / 43 / 52**. These are enabled scheduled entries, not simultaneous live-enemy counts. Groups can overlap when earlier enemies survive.

Align the forward guns with required targets while moving around incoming shots. If carried, select Field Repair or coolant with Cycle and use Special: they restore 25 or 30 energy respectively and consume a real item. Shop purchases and refills still cost credits.

## Equipment supplied by the mission

The mission supplies three Field Repair kits when capacity allows (25 energy per real Special use) and a temporary Pulse Cannon trial if one is not already carried. The Pulse Cannon is an automatic primary; hold Fire. The trial is removed at mission end.
