# Iron Coast — Complete Campaign

Enable this optional assembly package in **Mods** to select all six Iron Coast
mission packages and their shared weapon and enemy dependencies. Review the
selected packages and apply changes from the main menu, then choose **Iron
Coast 1 — Breakwater** in mission selection to start the route.

Each mission is a separate mod. A mission can be enabled and played without
this campaign package. The assembly package changes campaign progression;
gameplay, generated SD/HD artwork, sounds, distinct stage bosses, the original
Iron Coast soundtrack and scripts remain in the mission and content packages.
Classic foes reference the original catalog's enemy definitions, retaining
their native flight paths and firing behavior.

The campaign portrait reuses Mission 1's generated briefing artwork, included
here so this package owns all artwork it references. Original game assets are
not copied into this mod.

See [the campaign guide](../../docs/iron-coast.md) for objectives, equipment
loans, controls and validation results. All packages use mod API 1. Exact
versions and package hashes are recorded in pilot saves.
